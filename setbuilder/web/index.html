Set up Set Builder

Two steps, then never again.

1 SoundCloud credentials
2 Music folder

1 · SoundCloud credentials

Set Builder reads public playlists using your own app credentials. Registration is self-serve but needs an Artist Pro account. Register an app →

Stored in ~/.setbuilder/credentials.json, never in the repo.

SoundCloud allows 50 tokens per 12 hours. Set Builder caches the token to disk and refreshes it rather than requesting new ones, so a normal day spends one or two.

2 · Your music folder

Most of your playlist is probably already on this machine. Matching to local files gives full-length audio and picks up BPM and key that Serato or Rekordbox already wrote into the tags.
